## Hi, I'm Julian

I'm an AI consultant and artist in Berlin, working as **Making AI Practical**. Most of what I do is
helping people and teams use AI tools properly — which usually turns out to mean stripping away the
hype and finding the two or three things that genuinely save them a day a week.

I build small tools for myself along the way. When one turns out to be useful, I put it here for
free.

### What's here

**[Claude Code Fuel Gauge](https://github.com/makingaipractical/claude-code-fuel-gauge)** — a VS Code
extension that puts four Claude Code readouts in your status bar: how full the context window is,
how long your prompt cache has left, which model and effort level you're running, and how close you
are to your usage limits.

It makes no network calls, has no account and no API key, and reads nothing but the files Claude
Code already writes on your own disk. Install it from the
[VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=makingaipractical.claude-code-fuel-gauge)
or from [Open VSX](https://open-vsx.org/extension/makingaipractical/claude-code-fuel-gauge) if you
use VSCodium, Cursor or another fork.

These are free because I built them for myself first. If one is useful to you too, take it.
